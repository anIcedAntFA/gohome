## 🎯 Overview

**v1.3** is a major architectural upgrade that modernizes the CLI framework while maintaining backward compatibility for most use cases.

### What's New in v1.3?

- ✅ **Cobra/Viper Framework:** Modern CLI with subcommands and better UX
- ✅ **Multi-Format Config:** Support for JSON, YAML, and TOML
- ✅ **Environment Variables:** Configure via `GOHOME_*` env vars
- ✅ **Shell Completions:** Auto-completion for bash, zsh, fish, powershell
- ✅ **Config Management:** New `config` subcommand for easy configuration
- ✅ **Improved Help:** Better organized help text with examples
- ✅ **100% Test Coverage:** Critical packages fully tested (parser, git, renderer)

### Migration Timeline

- **Recommended:** Migrate immediately for new features
- **Support:** v1.2 will receive security fixes only
- **EOL:** v1.2 end-of-life after 6 months (July 2026)

## ⚠️ Breaking Changes

### 1. Configuration File Format Change

**v1.2:**
```json
{
  "workspace": "/home/user/projects",
  "max_depth": 2,
  "author": "John Doe",
  "time_period": "24h",
  "format": "text"
}
```

**v1.3:**
```json
{
  "workspace": "/home/user/projects",
  "maxDepth": 2,
  "author": "John Doe",
  "days": 1,
  "format": "text",
  "style": "normal",
  "showIcon": true,
  "showScope": true
}
```

**Key Changes:**
- `max_depth` → `maxDepth` (camelCase)
- `time_period: "24h"` → `days: 1` (numeric)
- New fields: `style`, `showIcon`, `showScope`

### 2. Time Period Flags

**v1.2:**
```bash
gohome --period=24h
gohome --period=3d
```

**v1.3:**
```bash
gohome --days=1
gohome --days=3
# OR use new granular flags:
gohome --hours=24
gohome --minutes=120
```

**Migration:**
- `--period=24h` → `--days=1` or `--hours=24`
- `--period=3d` → `--days=3`
- `--period=1w` → `--days=7`

### 3. Command Structure Changes

**v1.2:**
```bash
gohome [flags]  # Only one command
```

**v1.3:**
```bash
gohome [command] [flags]  # Subcommand structure
gohome report [flags]     # Explicit report command
gohome config list        # New config management
gohome version            # Dedicated version command
```

**Backward Compatibility:**
- ✅ `gohome [flags]` still works (defaults to `report` command)
- ✅ All v1.2 flags still supported

## ✨ New Features

### 1. Multi-Format Configuration

v1.3 supports JSON, YAML, and TOML configuration files.

**JSON (default - `~/.gohome.json`):**
```json
{
  "workspace": "/home/user/projects",
  "author": "John Doe",
  "days": 1,
  "format": "table",
  "style": "markdown"
}
```

**YAML (`~/.gohome.yaml`):**
```yaml
workspace: /home/user/projects
author: John Doe
days: 1
format: table
style: markdown
showIcon: true
showScope: true
```

**TOML (`~/.gohome.toml`):**
```toml
workspace = "/home/user/projects"
author = "John Doe"
days = 1
format = "table"
style = "markdown"
showIcon = true
showScope = true
```

**Auto-Detection:**
- Viper automatically searches for `.gohome.{json,yaml,yml,toml}` in `$HOME`
- Specify custom config: `gohome --config=/path/to/config.yaml`

### 2. Environment Variables

Configure gohome via environment variables with `GOHOME_` prefix:

```bash
# Set via environment
export GOHOME_WORKSPACE=/home/user/projects
export GOHOME_AUTHOR="John Doe"
export GOHOME_DAYS=3
export GOHOME_FORMAT=table
export GOHOME_STYLE=markdown

# Run without flags
gohome
```

**Naming Convention:**
- Prefix: `GOHOME_`
- Uppercase flag name with underscores
- Examples:
  - `--workspace` → `GOHOME_WORKSPACE`
  - `--max-depth` → `GOHOME_MAX_DEPTH`
  - `--show-icon` → `GOHOME_SHOW_ICON`

**Precedence (highest to lowest):**
1. Command-line flags
2. Environment variables
3. Configuration file
4. Default values

### 3. Shell Completions

Enable auto-completion for your shell:

**Bash:**
```bash
# Install completion script
gohome completion bash > /etc/bash_completion.d/gohome

# Or for current session
source <(gohome completion bash)
```

**Zsh:**
```bash
# Install completion script
gohome completion zsh > "${fpath[1]}/_gohome"

# Or for current session
source <(gohome completion zsh)
```

**Fish:**
```bash
# Install completion script
gohome completion fish > ~/.config/fish/completions/gohome.fish

# Or for current session
gohome completion fish | source
```

**PowerShell:**
```powershell
# Install completion script
gohome completion powershell > gohome.ps1
. ./gohome.ps1
```

**Features:**
- Command completion (`gohome <TAB>` → shows `report`, `config`, `version`, `completion`)
- Flag completion (`gohome --<TAB>` → shows all available flags)
- Subcommand completion (`gohome config <TAB>` → shows `list`, `get`, `set`, `reset`)

### 4. Config Management Subcommand

New `config` command for easy configuration management:

```bash
# View all settings
gohome config list

# Get specific setting
gohome config get workspace
gohome config get days

# Set configuration values
gohome config set workspace /home/user/projects
gohome config set days 7
gohome config set format table

# Reset to defaults
gohome config reset
```

**Benefits:**
- No need to manually edit JSON files
- Validation of configuration values
- Easy viewing of current settings
- Quick reset to defaults

## 🔄 Configuration Migration

### Automatic Migration

v1.3 can read v1.2 configuration files, but you should migrate for best experience.

### Manual Migration Steps

**Step 1: Backup your old config**
```bash
cp ~/.gohome.json ~/.gohome.json.v1.2.backup
```

**Step 2: Use migration script (recommended)**
```bash
# Download migration helper
curl -sO https://raw.githubusercontent.com/anIcedAntFA/gohome/main/scripts/migrate-config.sh
chmod +x migrate-config.sh

# Run migration
./migrate-config.sh ~/.gohome.json
```

**Step 3: Or manually update config**
```bash
# Edit config file
nano ~/.gohome.json

# Update keys:
# - max_depth → maxDepth
# - time_period → days (convert 24h=1, 48h=2, etc.)
# - Add new fields: style, showIcon, showScope
```

**Step 4: Verify migration**
```bash
# View current config
gohome config list

# Test with your usual workflow
gohome
```

### Field Mapping Reference

| v1.2 Field | v1.3 Field | Notes |
|------------|------------|-------|
| `workspace` | `workspace` | No change |
| `max_depth` | `maxDepth` | CamelCase |
| `author` | `author` | No change |
| `time_period` | `days` | Convert: `24h`→`1`, `48h`→`2`, `7d`→`7` |
| `all_branches` | `allBranches` | CamelCase |
| `branch` | `branch` | No change |
| `format` | `format` | No change |
| N/A | `style` | **New:** `"normal"` or `"markdown"` |
| N/A | `showIcon` | **New:** `true`/`false` |
| N/A | `showScope` | **New:** `true`/`false` |
| N/A | `copy` | **New:** Auto-copy to clipboard |
| N/A | `save` | **New:** Save current flags to config |
| `tasks` | `tasks` | No change (still array of task objects) |

## 🔧 Command Changes

### Default Command Behavior

**v1.2:**
```bash
gohome [flags]  # Only way to generate report
```

**v1.3 (backward compatible):**
```bash
gohome [flags]        # Still works! (implicit "report" command)
gohome report [flags] # Explicit command (recommended for scripts)
```

### New Subcommands in v1.3

```bash
# Configuration management
gohome config list
gohome config get <key>
gohome config set <key> <value>
gohome config reset

# Version information
gohome version
gohome version --short

# Shell completions
gohome completion bash
gohome completion zsh
gohome completion fish
gohome completion powershell

# Help
gohome help
gohome report --help
gohome config --help
```

### Flag Changes

**No flags removed** - all v1.2 flags still work in v1.3.

**New flags in v1.3:**
```bash
--style           # Output style: normal, markdown (default: normal)
--show-icon       # Show emoji icons (default: true)
--show-scope      # Show commit scopes (default: true)
--copy            # Copy output to clipboard
--save            # Save current flags to config file
--config          # Specify custom config file path
```

## 🌐 Environment Variables

v1.3 introduces full environment variable support.

### Setting Environment Variables

**Temporary (current session):**
```bash
export GOHOME_WORKSPACE=/home/user/projects
export GOHOME_DAYS=3
gohome
```

**Permanent (add to shell profile):**

**Bash/Zsh (`~/.bashrc` or `~/.zshrc`):**
```bash
export GOHOME_WORKSPACE=/home/user/projects
export GOHOME_AUTHOR="John Doe"
export GOHOME_DAYS=7
export GOHOME_FORMAT=table
export GOHOME_STYLE=markdown
```

**Fish (`~/.config/fish/config.fish`):**
```fish
set -x GOHOME_WORKSPACE /home/user/projects
set -x GOHOME_AUTHOR "John Doe"
set -x GOHOME_DAYS 7
set -x GOHOME_FORMAT table
set -x GOHOME_STYLE markdown
```

### Complete Environment Variable Reference

```bash
# Workspace settings
GOHOME_WORKSPACE          # Workspace path
GOHOME_MAX_DEPTH          # Scan depth (default: 2)

# Git settings
GOHOME_AUTHOR             # Git author name
GOHOME_ALL_BRANCHES       # Include all branches (true/false)
GOHOME_BRANCH             # Specific branch name

# Time period (mutually exclusive)
GOHOME_DAYS               # Number of days
GOHOME_HOURS              # Number of hours
GOHOME_MINUTES            # Number of minutes
GOHOME_SECONDS            # Number of seconds
GOHOME_WEEKS              # Number of weeks

# Output settings
GOHOME_FORMAT             # Output format: text, table
GOHOME_STYLE              # Style: normal, markdown
GOHOME_SHOW_ICON          # Show icons (true/false)
GOHOME_SHOW_SCOPE         # Show scopes (true/false)
GOHOME_COPY               # Copy to clipboard (true/false)

# Configuration
GOHOME_CONFIG             # Custom config file path
GOHOME_SAVE               # Save to config (true/false)
```

## 🐚 Shell Completions

### Installation Instructions

#### Bash

**System-wide (requires sudo):**
```bash
sudo gohome completion bash > /etc/bash_completion.d/gohome
```

**User-only:**
```bash
mkdir -p ~/.local/share/bash-completion/completions
gohome completion bash > ~/.local/share/bash-completion/completions/gohome
```

**Current session:**
```bash
source <(gohome completion bash)
```

#### Zsh

**System-wide (requires sudo):**
```bash
sudo gohome completion zsh > /usr/local/share/zsh/site-functions/_gohome
```

**User-only:**
```bash
# Find your zsh fpath
echo $fpath

# Install to first directory in fpath
gohome completion zsh > "${fpath[1]}/_gohome"

# Rebuild completion cache
rm -f ~/.zcompdump
compinit
```

**Current session:**
```bash
source <(gohome completion zsh)
```

#### Fish

**System-wide (requires sudo):**
```bash
sudo gohome completion fish > /usr/share/fish/vendor_completions.d/gohome.fish
```

**User-only:**
```bash
gohome completion fish > ~/.config/fish/completions/gohome.fish
```

**Current session:**
```bash
gohome completion fish | source
```

#### PowerShell

**Current user profile:**
```powershell
# Generate completion script
gohome completion powershell > gohome.ps1

# Add to profile
Add-Content $PROFILE "`n. $(Get-Location)\gohome.ps1"
```

**Current session:**
```powershell
gohome completion powershell | Out-String | Invoke-Expression
```

### Testing Completions

After installation, test completions:

```bash
# Press TAB after these commands
gohome <TAB>                    # Shows: report, config, version, completion, help
gohome config <TAB>             # Shows: list, get, set, reset
gohome --<TAB>                  # Shows all available flags
gohome --format=<TAB>           # Shows: text, table
gohome --style=<TAB>            # Shows: normal, markdown
```

## 🔍 Troubleshooting

### Issue: "command not found: gohome"

**Cause:** v1.3 not in PATH or old version still present.

**Solution:**
```bash
# Check version
gohome version

# If shows v1.2, remove old install
rm $(which gohome)

# Reinstall v1.3
curl -sS https://get.ngockhoi96.dev/gohome | sh

# Verify
gohome version  # Should show v1.3.x
```

### Issue: Configuration not loading

**Cause:** Config file format incompatible or wrong location.

**Solution:**
```bash
# Check config location
gohome config list  # Shows loaded config

# Verify file exists
ls -la ~/.gohome.json

# Check file format
cat ~/.gohome.json | jq .  # Should parse as valid JSON

# Reset to defaults if corrupt
gohome config reset
```

### Issue: "unknown flag: --period"

**Cause:** Using old v1.2 flag syntax.

**Solution:**
```bash
# OLD (v1.2): gohome --period=24h
# NEW (v1.3): gohome --days=1

# Or use granular flags
gohome --hours=24
gohome --minutes=1440
```

### Issue: Shell completions not working

**Cause:** Completions not installed or sourced correctly.

**Solution:**
```bash
# Bash
source <(gohome completion bash)

# Zsh
source <(gohome completion zsh)
# Then rebuild cache
rm ~/.zcompdump && compinit

# Fish
gohome completion fish | source
```

### Issue: Environment variables not working

**Cause:** Variables not exported or wrong naming.

**Solution:**
```bash
# Must use EXPORT
export GOHOME_WORKSPACE=/home/user/projects  # ✅ Correct
GOHOME_WORKSPACE=/home/user/projects         # ❌ Wrong (not exported)

# Check if set
env | grep GOHOME

# Verify precedence
gohome config list  # Should show env var values
```

### Issue: "config set" not persisting

**Cause:** Trying to set invalid key or value.

**Solution:**
```bash
# Check valid keys
gohome config list

# Use exact key names (case-sensitive)
gohome config set days 7        # ✅ Correct
gohome config set Days 7        # ❌ Wrong (capital D)

# Some keys need quotes
gohome config set workspace "/home/user/projects"
```
